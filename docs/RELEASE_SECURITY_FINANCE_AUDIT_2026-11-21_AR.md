## منهج الإثبات
- **PASS مثبت:** اختبار فعلي أجري وانتهى بنجاح وله سجل تشغيل / تقرير.
- **IMPLEMENTED UNVERIFIED:** كود أو SQL رُفع، لكن اختبار التنفيذ لم يعمل بعد.
- **OPEN:** غير مُنفذ أو غير متحقق منه، يمنع أو يقيّد الإطلاق.
- **NOT TESTED:** يتطلب خادمًا وأجهزة وشبكة إنتاج مماثلة أو تصريحًا لاختبار اختراق.
- لا تعني الفحوص الساكنة أو CodeQL عدم وجود ثغرات. لا تستخدم بيانات عملاء حقيقية في الاختبارات.

## إجراءات أمان أضيفت في PR #65
1. `server/sql/006_fin18_approved_ledger_source_guard.sql` يرفض قيدًا معتمدًا لا يطابق المصدر (العملة، المبلغ، نوع الدين/الدفعة، التاجر، العميل، العلاقة، مرجع العكس) أو لم يعتمد مصدره. لم نغيّر قيودًا تاريخية بصمت.
2. `server/test/fin18_approved_ledger_source_guard.integration.test.mjs` يختبر محاولة SQL مباشرة بمبلغ **999 SAR** مقابل مطالبة **100 YER** ويختبر ترحيل مطالبة صحيحة بعد الموافقة.
3. `server/src/http.mjs`: حد ترويسات 8KiB، مهلة ترويسات 10 ثوانٍ، طلبات 15 ثانية، keep-alive خمس ثوانٍ، 100 طلب لكل اتصال، مع `X-Request-ID` وترويسات no-store/nosniff/frame denial/referrer denial. **ليست بديلًا لبوابة TLS أو WAF أو موزع Rate Limiter**.
4. `server/test/security_hardening.test.mjs` يغطي حدود الشبكة ومنع تسرب تفاصيل الخطأ إلى الاستجابة والسجل.
5. مسجل Flutter يخزن 40 حدثًا كحد أقصى، بالوقت UTC ونوع الخطأ فقط. لا يلتقط نص الاستثناء/مكدسه/رقم هاتف/مبلغ/Token ولا يرسل إلى GitHub أو أي طرف. يستطيع المستخدم نسخ التقرير المنقح يدويًا من الضبط.
6. Dependabot لاقتراح تحديثات npm وFlutter وGitHub Actions. CI ينفذ npm audit وCodeQL JavaScript عند سماح خدمات GitHub. **عدم تشغيل CodeQL لا يساوي PASS**.
7. محاولة إنشاء Issue عند فشل بوابة CI تقتصر على معرف Commit ورابط التشغيل؛ **ممنوع نشر سجلات المستخدمين أو الأسرار في GitHub Issues**.

## سياسة خصوصية تشخيصية
**المسموح في بلاغ التشخيص:** التصنيف المحدد مسبقًا، توقيت UTC، معرف حادث مولّد خادميًا، مكون الخدمة، ورابط Build لا يحتوي أسرارًا.  
**المحظور:** رمز OTP أو JWT، الأرقام الهاتفية، الصور، عناوين منزلية، اسم العميل، محتوى المطالبة، حسابات ومبالغ مالية، SQL/Stacktrace للمستخدمين، مفاتيح API، body، Authorization، query-string الحساسة.  
الاحتفاظ والإرسال التلقائي لا يفعّلان قبل سياسة خصوصية وصلاحيات دعم متفق عليها.
