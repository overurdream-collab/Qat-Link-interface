## 3. البنية ومكونات التكامل
- **FIN25:** خادم/بوابة OTP يستقبل طلب إثبات الرمز من مسار الهوية، وبوابة هاتف Samsung ترسل الرسائل عبر شريحة SIM، وتستخدم نقاط API للتسجيل/التحقق/النبض والصف. إرسال حقيقي واحد على الأقل نجح في مرحلة التشغيل السابقة، ثم ظهر فشل مرتبط بنفاد رصيد الشريحة، لا يُعد هذا اعتمادًا مستمرًا للخدمة.
- **P0 Identity:** خدمة هوية منفصلة تُصدر RS256 JWT، تتحقق من إثبات OTP من FIN25، تحفظ سجل هوية مستقلًا في PostgreSQL، ثم تطلب تهيئة الحساب في FIN08. لا تمنح علاقة عميل/تاجر موافقة مالية تلقائية.
- **FIN08:** خادم مالي مستقل. في اختبار HTTP المذكور **حُوكي بـHTTP محلي** ولم يُختبر فيه مسار الإنتاج الفعلي.
- **Flutter:** واجهات العميل/التاجر، تسجيل الدخول، خدمة جلسات الهوية وعميل OTP، شاشات الاختبار/الهوية.
- **PostgreSQL 16:** مخطط مستقل للهوية، **لا تطبقه على قاعدة FIN25 SMS أو دفتر FIN08 المالي**.
- **Caddy:** توزيع المسارات إلى الخدمات والحد من إتاحة واجهة طلب OTP عموميًا. بعض قواعد `remote_ip` قد تتصرف بشكل غير متوقع خلف الوكيل/حاويات Docker؛ تتطلب اختبار شبكة وأمان حقيقي.

**مخطط تدفق متوقع:** الهاتف/Flutter → FIN25 (SMS + إثبات رمز) → P0 Identity (الهوية + JWT) → FIN08 (تهيئة الحساب). يوجد فرق بين هذا التصميم وبين إثبات التشغيل الطرفي الكامل؛ لم يتم اعتماد الثاني بعد.

## 6. الأعطال التي عولجت والدروس
1. **مرجع Identity غير موجود محليًا:** جُلب بــ`git fetch --no-tags origin +refs/heads/feat/p0-auth-identity-integration-20261118:refs/remotes/origin/feat/p0-auth-identity-integration-20261118`.
2. **فحص MERGE_HEAD داخل Worktree:** `.git` قد يكون ملفًا؛ الطريقة الصحيحة: `git rev-parse --git-path MERGE_HEAD`، ثم `Test-Path` للمسار الناتج.
3. **PostgreSQL أثناء bootstrap:** `pg_isready` دون TCP قد يتصل بالخادم المؤقت قبل إنشاء `identity_ci`. نجح الاختبار بالانتظار عبر `pg_isready -h 127.0.0.1` داخل الحاوية، ثم استعلام فعلي قبل تطبيق المخطط.
4. **فشل PowerShell عند رسائل stderr المتوقعة:** لا تجعل رسائل بداية Docker/psql تنهي الحلقة؛ اجعل فحوص الجاهزية قابلة للتحمل واستخدم سجلات Docker للتشخيص. لا تغيّر `ExecutionPolicy` لتشغيل npm؛ استخدم `npm.cmd`.
5. **لا `server/package-lock.json` في الفرع:** فشل `npm ci`. نجح `npm.cmd install --omit=dev --no-save --package-lock=false --ignore-scripts --no-audit --no-fund`. لاحقًا يجب معالجة reproducible builds وخطة lockfile مراجَعة.
6. **اختبار HTTP لا يعمل على Windows:** `spawn(process.execPath,...,{cwd:new URL('../',import.meta.url).pathname})` أنتج `ENOENT`. صُحح إلى `cwd:new URL('../',import.meta.url)`، ثم نجح HTTP.
7. **تصنيف lint الأول أخطأ:** كان يتوقع رمز `•` بينما مخرجات Flutter من نمط `info - ...`. روجع التقرير وعدلت طريقة تشغيل التحليل إلى `--no-fatal-infos`.
8. **تنسيق أربعة ملفات مدمجة ثم Caddy:** عولجت ملاحظات نهاية الملف؛ `git diff --check` أصبح نظيفًا.
9. **غياب Flutter artifacts أولًا:** نُفذ `flutter pub get` ثم `flutter test --no-pub`؛ ملفات البناء المحلي غير متتبعة ويجب ألا تدخل PR دون قرار.
