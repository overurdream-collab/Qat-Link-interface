# FIN-11 — بيان مطالبات التاجر المعلقة للمشاركة اليدوية

يسمح للتاجر بنسخ **بيان مبالغ معلقة وغير معتمدة من العميل** إلى الحافظة ثم اختيار جهة الإرسال بنفسه (واتساب أو أي تطبيق آخر)، دون مزاعم الموافقة أو إنشاء إيصال أو إرسال آلي.

- تجمع الواجهة كل صفحات المطالبات من خادم التاجر (وليس أول 50 فقط)، ولا تنسخ بياناً ناقصاً إذا فشلت صفحة أو تكرر cursor.
- تستبعد الديون **المعتمدة** والمرفوضة من البيان الموسوم «معلق»، وتحافظ على المبالغ كنصوص Decimal، وتضع مجموعاً مستقلاً لكل عملة YER/SAR/USD دون تجميع مختلف العملات.
- تأكيد صريح للتاجر قبل نسخ البيانات مع تحذير خصوصية رقم المستلم؛ لا اتصال API بواتساب ولا إرسال تلقائي.
- البيانات في هذا المسار تعتمد على FIN-09/FIN-08 API وجلسة التاجر الموثقة فقط؛ واجهة Login وOTP لم تُربط بالإنتاج بعد.
- لا يؤثر نسخ البيان أو عرضه على الموافقات الثنائية، ولا يضيف حركة مالية معتمدة.

**حدود:** هذا ليس كشفاً محاسبياً شاملاً للديون المعتمدة والتسديدات، بل بيان أحادي الجانب للمطالبات غير المعتمدة. الكشف الشامل لاحقاً يستند لدفتر حركات موحّد وخدمة صلاحيات وتصدير PDF خادمية.
