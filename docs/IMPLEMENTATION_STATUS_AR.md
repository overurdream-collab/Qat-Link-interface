# حالة التنفيذ الفعلية — مقوتي لنك

**لقطة فنية مؤرخة:** 2026-11-15  
**أساس القراءة:** main عند 5e933184c301e6589a3a5eaaaaf28ce3d11766b5، بالإضافة إلى التغيير الحالي في فرع المراجعة. تتحدث اللقطة عند دمج PR ويُستبدل رابط فحص CI بالنتيجة الفعلية.  
**تحذير:** «المكوّن موجود» لا تعني أن الخدمة متصلة، و«الاختبار ناجح» لا يثبت عملها بين جهازين حقيقيين.

## تعريف الحالات
- **مختبر محلياً في CI**: كود وWidget/Unit tests عند GitHub، ضمن بيئة اختبار Flutter.
- **واجهة أو منطق جاهز للربط**: ليس API أو خدمة إنتاجية.
- **غير متصل**: لا يوجد خادم أو حفظ أو جلسة أو تبليغ فعلي.
- **قرار مؤجل**: تحتاج موافقة المنتج ولا تُفعّل بالتخمين.

## آخر تعديل مطلوب

**قرار UX-02:** ينتقل تذكير الحجز من «تأكيد ثم عدد ثم تأكيد» إلى «فتح التذكير = عرض العدد مباشرة، مع تأكيد واحد أو تجاهل».  
**الملفات:** lib/widgets/merchant_space/reminder_quick_booking_sheet.dart وtest/screens/reminder_quick_booking_sheet_widget_test.dart.  
**إغلاقه:** يجب أن تمر اختبارات الكود في الفرع وmain بعد الدمج؛ لا يُعد جاهزاً للإرسال دون Backend.

## حدود إطلاق النسخة

لا تعلن إطلاق التطبيق للمستخدمين الحقيقيين دون:
1. إثبات مصادقة وربط جهاز/جلسة وسلطة أدوار خادمية.
2. خدمة بيانات دائمة وتزامن علاقات وموافقات وحركات وحجوزات، دون ازدواج.
3. ضمان أن سجل الديون المعتمدة لا يتغير بدون موافقة الطرف الثاني وتدقيق.
4. اختبار إغلاق الحجوزات بعد الوقت واستهداف التذكيرات وتفضيلات العميل على جهاز فعلي.
5. تجربة إرسال واستقبال وتجاهل وتأكيد حجز وفشل الشبكة وإعادة المحاولة على أكثر من جهاز.
6. مراجعة الخصوصية والأمن واختبار تعارض العملات والحدود والباقات.
