# تحديث واجهة الدخول من المرجع البصري الجديد — مقوتي لينك
التاريخ: 2026-11-19. فرع العمل: `feat/p0-auth-identity-integration-20261118`، PR #61، غير مدمج.

## المرجع وحدوده
الصورة التي قدمها المستخدم مرجع للإخراج البصري وليست مواصفات لإلغاء نظام المصادقة المعتمد. طلب المستخدم صراحةً: «خذ منها مانحتاج فقط ويواكب متطلباتنا».

## ما اعتمدناه
- وضوح التسلسل: الشعار الرسمي، تعريف الخدمة، جملة ثقة موجزة، رقم الجوال، زر إجراء أساسي، ثم إنشاء حساب.
- الهوية التركوازية والذهبية في زر SMS وإطار منطقة الشعار، مع استمرار دعم الوضع الداكن والخلفية المعتمدة.
- إبراز «مساعدك المالي الذكي» و«لتجارة أنجح» داخل `AuthBrandHero`.
- إبراز مبدأ الدفتر المشترك: «التاجر يسجّل، والعميل يعتمد». هذه عبارة تعريفية لا تتجاوز الموافقات الثنائية للعمليات أو ربط العملاء.
- تمييز واضح بين `الدخول برمز تحقق SMS` (المسار الجاري تطويره والمتصل بخدمة الهوية عند نشرها) وبين `الدخول بالرمز الخاص (قيد التطوير)` (لا يصدر جلسة ولا يفتح الماليات).
- المحافظة على مدخل الهاتف اليمني `+967`، ورفض دخول مفترض من ملء الحقول فقط، والمحافظة على روابط المعاينة في Debug حصراً.

## ما استبعدناه عمداً
- حقول البريد الإلكتروني واسم المستخدم وكلمة المرور الموجودة في الصورة؛ غير مدعومة بعقد P0 الحالي.
- زر «تذكرني» أو «نسيت كلمة المرور» بآلية وهمية: لا نقدم حفظ جلسات أو استرجاعاً غير موصول بالخادم.
- نسخ واجهة المصوّر حرفياً بما يتسبب في ارتفاع مفرط أو ضعف قراءة النماذج على الهواتف الصغيرة.
- اعتماد القات أو الحجوزات محاسبياً من أي عنصر زخرفي.
- استبدال الألوان الدلالية للحالات المالية أو تغيير خادم FIN25/بوابة Samsung.

## الملفات المتغيرة
1. `lib/widgets/auth/auth_brand_hero.dart` — تقليل الارتفاع، إضافة شعار الخدمة وجملة «لتجارة أنجح» وضبط إطار ذهبي متزن؛ commit `aaad70702b9ece4534df7f282466e7485a3307da`.
2. `lib/screens/login_screen.dart` — إبراز SMS CTA وإعلان الموافقة الثنائية وفصل المدخل غير المفعّل بصرياً؛ commit `976e09cf15b4818050fb4c33a8a5eca79abcf7e7`.
3. `test/screens/auth_screens_widget_test.dart` — التحقق من الجملة التوضيحية، زر SMS، وعدم إدخال بريد/كلمة مرور أو كشف بيانات مالية؛ commit `2858b8a1e7c82d236e3f4e350c3dbfe48bb5ee91`.

## معايير القبول
- `flutter analyze --no-fatal-infos` و`flutter test` كاملان؛ لا تعلن نجاحاً قبل تأكيد CI للـSHA نفسه.
- شاشة صغيرة (ارتفاع 600px) يجب أن تسمح بالتمرير حتى زر إنشاء الحساب؛ اختبار widget يمرر إلى العنصر قبل الضغط.
- صورة الخلفية الرسمية تُستعمل مع تباين مقروء؛ لا تدمج صورة المرجع مباشرة بما فيها حقول دخول غير حقيقية.
- أصول الشعار في GitHub ما زالت مصغّرة: لا تعتبر التصميم عالي الدقة قبل استبدالها بالأصل واعتماد فحص SHA256 وفق `scripts/check_maqwati_brand_assets.py`.
- لا نشر، لا دمج، لا تعديل قاعدة البيانات أو Docker أو مفاتيح SMS، ولا ادعاء بأن خدمة المصادقة نُشرت أو أجري اختبار هاتف حقيقي.
