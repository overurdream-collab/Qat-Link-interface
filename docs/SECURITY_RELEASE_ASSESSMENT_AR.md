**الحالة:** لا يجوز الإطلاق العام بناءً على هذا التقييم.

## 1. الخلاصة

الأساس الأمني للخادم أفضل من المتوقع: تحقق JWT صارم، فصل أدوار، تحقق ملكية الموارد، أموال عشرية، Idempotency، وقيود قاعدة بيانات تمنع التلاعب. لكن **سطح الإطلاق غير آمن بعد**، وأهم المخاطر:

1. مسارات إدارة FIN25 مكشوفة على الحافة العامة خلف مفتاح فقط.
2. حدود المعدل تنهار خلف Caddy لأنها تعتمد عنوان الـpeer المباشر.
3. بوابة OTP المحلية تعتمد `remote_ip 127.0.0.1` وقد لا تعمل داخل Docker.
4. لا WAF ولا تحديد معدل على الحافة.
5. الجلسة في Flutter غير محفوظة بأمان ولا قابلة للإبطال خادميًا.
6. لا فحص أسرار آلي ولا اختبار أمني حي.
7. طوبولوجيا النشر قد تمنع وصول Caddy إلى الهوية أصلًا.

## 3. النتائج

### SEC-01 — مسارات إدارة FIN25 عامة (حرج)

**الوصف:** `/v1/gateway/enroll`, `/approve`, `/revoke` تمر عبر matcher عام في Caddy وتُحمى فقط بـ`X-FIN25-ADMIN-KEY`.
**الدليل:** `deploy/fin25/Caddyfile:3-6` و`server/src/fin25_gateway_enrollment.mjs:22,34`.
**الأثر:** أي تسريب/تخمين للمفتاح يسمح بتسجيل أو اعتماد أو إبطال أجهزة.
**التوصية:** تقييدها بشبكة إدارية/VPN أو mTLS أو مصادقة إدارية كاملة + تحديد معدل + تدوير المفتاح + تسجيل كل محاولة.
**الحالة:** مفتوح.

### SEC-02 — انهيار حدود المعدل خلف الوكيل (حرج)

**الوصف:** محدد الجلسات والتسجيل يعتمد `req.socket.remoteAddress` ويتجاهل رؤوس الوكيل، فتصبح كل الطلبات من عنوان Caddy نفسه.
**الدليل:** `server/src/identity_session_limiter.mjs:1-3` و`identity_server.mjs:56-58,93-98` و`fin25_gateway_enrollment.mjs:10-18`.
**الأثر:** حد 60/دقيقة للجلسات و5/ساعة للتسجيل يصبح عالميًا، أي تعطيل مقصود أو استهلاك كامل.
**التوصية:** تحديد معدل على الحافة (Caddy/WAF) + تمرير IP موثوق + مفاتيح معدل مركبة (IP + هاتف + جهاز).
**الحالة:** مفتوح.

### SEC-03 — بوابة OTP المحلية قد لا تعمل داخل Docker (عالي)

**الوصف:** شرط `remote_ip 127.0.0.1 ::1` في Caddy.
**الدليل:** `deploy/fin25/Caddyfile:9`.
**الأثر:** إما تعطل مسار المشغّل، أو اعتماد خاطئ على أن الطلب محلي.
**التوصية:** اختبار حي داخل الحاوية، واستخدام شبكة إدارية موثوقة بدل الاعتماد على loopback.
**الحالة:** مفتوح/غير مثبت.

### SEC-04 — لا WAF ولا تحديد معدل على الحافة (عالي)

**الوصف:** لا `rate_limit` موزع في Caddyfile، والوثائق تعترف بغياب WAF. أُضيف حد تطبيقي لكل حساب لمسارات FIN08/FIN13 (قراءة/كتابة) داخل خدمة الهوية.
**الدليل:** `deploy/fin25/Caddyfile` و`identity_finance_limiter.mjs` و`docs/IDENTITY_HTTPS_SECURITY_GATE_AR_2026-11-21.md:14-15`.
**الأثر:** الحد الحالي يحمي نسخة هوية واحدة؛ تبقى إساءة OTP/الحركة الموزعة والحمل على الحافة دون WAF.
**التوصية:** WAF أو Caddy rate limit موزع + حظر سلوكي + مراقبة.
**الحالة:** جزئي.

### SEC-05 — الجلسة في Flutter غير قابلة للإبطال خادميًا (عالي)

**الوصف:** أُضيف تخزين مشفّر للرمز (`flutter_secure_storage`)، استعادة بعد تأكيد `/v1/identity/me`، وتجديد/إبطال خادمي عبر `identity_sessions` مع تدوير رمز التجديد لمرة واحدة. يُربط التجديد بمعرف جهاز ثابت في التخزين الآمن؛ ما زال ناقصًا اختبار ذلك على جهاز حقيقي.
**الدليل:** `lib/services/session_store.dart` و`lib/screens/session_gate.dart` و`lib/services/identity_session_client.dart` (`confirm`).
**الأثر:** إعادة التشغيل تستعيد الجلسة الصالحة، لكن الجلسة المسروقة تبقى صالحة حتى الانتهاء أو إبطال المفتاح.
**التوصية:** اختبار على Android/iOS + مراقبة إعادة استخدام رمز التجديد.
**الحالة:** جزئي.

### SEC-06 — مسارات مالية غير مكشوفة/غير محمية بالكامل (عالي)

**الوصف:** Caddy يعرض قراءة FIN08/FIN13 وكتابة محددة عبر وكيل الهوية بقائمة سماح صريحة. الكتابة تمر بتحقق جلسة/دور، وحد 64KB، و`Idempotency-Key`، ومهلة، ولا تُمرر URLs/رؤوس عشوائية. ما زال ناقصًا: تحديد معدل كتابة على الحافة، تدقيق مركزي، واختبار حي للملكية.
**الدليل:** `deploy/fin25/Caddyfile` و`identity_fin08_write_proxy.mjs` و`identity_fin08_read_proxy.mjs`.
**الأثر:** إما تعطل المنتج أو فتح سطوح جديدة بسرعة دون مراجعة.
**التوصية:** قائمة سماح صريحة لكل مسار مع اختبارات سلبية لكل واحد.
**الحالة:** جزئي.

### SEC-07 — لا فحص أسرار آلي (عالي)

**الوصف:** لا secret scanning في CI ولا فحص تاريخ Git.
**الدليل:** لا خطوة `gitleaks/trufflehog` في `.github/workflows/*`.
**التوصية:** إضافة فحص أسرار على PR وعلى التاريخ، ومنع الدمج عند النجاح.
**الحالة:** مفتوح.

### SEC-08 — `PG_SSL` معطّل افتراضيًا وFIN25 بلا SSL (متوسط)

**الدليل:** `server/src/index.mjs:8` و`server/src/identity_server.mjs:31-32` و`fin25_gateway_enrollment.mjs:8`.
**التوصية:** إلزام TLS لقواعد البيانات في الإنتاج أو ضبطه صراحةً مع توثيق.
**الحالة:** مفتوح.

### SEC-09 — حد أدنى ضعيف لأسرار OTP (متوسط)

**الوصف:** يتحقق فقط من وجود `OTP_HMAC_SECRET` و`OTP_INTERNAL_API_KEY`، لا الطول/العشوائية.
**الدليل:** `server/src/fin25_otp_transport.mjs:11-14`.
**التوصية:** حد أدنى 32 بايت عشوائي + رفض القيم الضعيفة.
**الحالة:** مفتوح.

### SEC-10 — خطأ 500 لمفتاح 2048-bit (منخفض)

**الوصف:** كان المسار يقبل `>=2048` ثم البصمة تتطلب 3072.
**الدليل:** `fin25_gateway_enrollment.mjs:40-42` و`gateway_device_crypto.mjs:4-8`.
**التوصية:** توحيد الحد والتحقق قبل التخزين وإرجاع 400.
**الحالة:** مغلق في الكود بتاريخ 2026-11-22 (توحيد الحد عند 3072)؛ ينتظر اختبار HTTP فعلي.

### SEC-11 — لا تنظيف للتحديات/Nonces/المهام المنتهية (متوسط)

**الدليل:** `server/sql/009_fin25_gateway_isolated.sql:2-24` و`010_fin25_otp_isolated.sql:2-23`.
**الأثر:** تضخم الجداول وبطء تدريجي.
**التوصية:** مهمة تنظيف دورية آمنة + فهارس مناسبة.
**الحالة:** مفتوح.

### SEC-12 — لا قراءة/تصدير لسجل التدقيق (متوسط)

**الدليل:** كتابة فقط في `server/src/store.mjs:61-65`، لا مسار قراءة.
**التوصية:** API إداري للقراءة والتصدير مع صلاحيات وتدقيق الوصول.
**الحالة:** مفتوح.

### SEC-13 — لا نسخ احتياطي/استعادة مجرب (عالي تشغيليًا)

**الدليل:** إجراء موثق فقط في `docs/FIN19_PRODUCTION_ROLLOUT_AR.md:3-4`.
**التوصية:** اختبار استعادة فعلي قبل أي UAT مالي، مع RPO/RTO.
**الحالة:** مفتوح.

### SEC-14 — لا اختبار أمني حي/اختراق (عالي)

**الوصف:** الاختبارات الحالية وحدات ومحاكاة؛ لا اختبار وصول أفقي حي، ولا سباقات على خادم حقيقي.
**التوصية:** حزمة اختبارات سلبية على بيئة اختبار معزولة قبل الإطلاق.
**الحالة:** مفتوح.

### SEC-15 — حدود الحافة وTLS مؤقتة (عالي)

**الدليل:** `docs/IDENTITY_HTTPS_SECURITY_GATE_AR_2026-11-21.md:3,10` و`UNIFIED_AUTH_RELEASE_GATE_AR.md:23-32`.

**الحالة:** مفتوح.
