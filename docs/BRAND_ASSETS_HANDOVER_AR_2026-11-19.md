# هوية مقوتي لينك — تسليم التصميمات 2026-11-19

## القرار
اعتماد صورتَي المالك المرفوعتين في المحادثة كمرجع تصميم، لا استبدال الشخصية بشخصية أخرى:
- خلفية شاشة الدخول: الشخصية اليمنية بالعمامة والصديري التركوازي والجنبية، ومعمار صنعاء والفراغ الفاتح للنص.
- الشعار الأفقي: الصورة الدائرية للشخصية والنص الصحيح **«مقوتي لينك»** بالتركوازي الداكن مع زخرفة ذهبية.

## مسارات الأصول في Flutter
- `assets/images/maqwati_login_background.jpg` — الخلفية.
- `assets/images/maqwati_horizontal_logo.jpg` — الشعار.
- `pubspec.yaml` يتضمن `assets/images/` بالفعل، ولا حاجة لتعديل التهيئة.
- `lib/widgets/auth/auth_brand_hero.dart` يحتوي `MaqwatiBrandMark` والقيم البصرية المركزية.
- `lib/screens/login_screen.dart` يستخدم الخلفية بتغطية للشاشة وطبقة تباين للنموذج.
- `lib/screens/registration_screen.dart` يعرض الشعار عبر `AuthBrandHero(compact:true)`.
- `lib/widgets/app_chrome.dart` يعرض الشخصية داخل شريط التاجر.
- عنوان `lib/main.dart` أصبح `مقوتي لينك` بالياء الصحيحة.

## اختبارات القبول
1. `flutter analyze --no-fatal-infos` دون أخطاء.
2. `flutter test` بما فيه `test/theme/maqwati_brand_assets_test.dart`.
3. شاشتا الدخول والتسجيل في `dark/light`، أحجام صغيرة وكبيرة، RTL عربي، شعار لا يقطع الحقول.
4. صورة الشعار تظهر دون إنترنت، ولا يتم تحميل الصورة من الإنترنت وقت التشغيل.
5. لا تتغير أي قواعد الموافقة المالية أو التسجيل المصادق؛ التعديل تجميلي فقط.
6. قبل الإعلان عن جودة الإنتاج، تحقَّق من أحجام الصورة المصغرة مقابل الأصل؛ وضع النسخ المصغرة الحالي **مؤقت**.

## APK بصري للمعاينة
`.github/workflows/p0-auth-ci.yml` يبني الآن Debug APK للتطبيق الرئيسي ويرفع الأثر باسم `maqwati-branded-login-preview-apk` إذا اجتاز التوقيع والبناء، مع `retention-days: 7`. هذا **ليس** APK دخول مالي فعلي، لأن عنوان `IDENTITY_API_BASE_URL` لم يُهيأ وخدمة الهوية غير منشورة. توقيع debug يختلف عن تطبيق بوابة SMS ولا يجوز تثبيته فوق تطبيق البوابة. رابط GitHub Actions الفعلي ونتيجته يثبتان بعد انتهاء CI.
