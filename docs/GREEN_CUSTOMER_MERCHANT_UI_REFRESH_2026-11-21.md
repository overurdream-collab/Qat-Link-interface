# تعديلات واجهات التاجر والعميل — الهوية الخضراء المعزولة

التاريخ: 21 نوفمبر 2026

## قرارات المالك المطبقة على الفرع الأخضر فقط
1. **الرئيسية للعميل:** تبدأ بنفس بانرات التاجر السبعة المعتمدة، ثم ملخص العملات الثلاث **YER / SAR / USD** على هيئة `PageView` بعرض شريحة واحدة تقريباً؛ تحريك تلقائي كل ست ثوانٍ، وسحب يدوي، وتوقف الحركة عند اللمس. لا جمع لعملتين ولا إدراج طلبات معلقة في الرصيد المعتمد.
2. **الاستوديو:** زر ثالث مركزي دائري كبير بارتفاع بصري فوق الشريط، ويستند إلى خلفية نصف دائرية من لون شريط التنقل نفسه. لا يغير الصلاحيات أو منطق الحجوزات.
3. **الضبط:** شاشة مشتركة للتاجر والعميل بعنوان واضح، وتحتوي الاسم، العنوان، الجوال، تغيير كلمة المرور، الباقات، الخصوصية والأمان، وحول التطبيق. عرض البيانات غير المتصلة توضيحي فقط؛ تغيير كلمة المرور والباقات **غير مفعّلين** إلى حين توصيل جلسة Identity موثقة وخدمة الاشتراكات. لا تُنشأ بيانات شخصية وهمية.
4. **أزرار الرأس:** بترتيب مرئي RTL من اليمين إلى اليسار: التنبيهات ← الثيم ← الضبط.
5. **سجل حركة التاجر:** حذف أيقونة «تصدير الحركة» المكررة في أعلى الشاشة، مع إبقاء «إصدار التقرير» أسفل الصفحة كما كانت دون تغيير الحسابات أو تصدير PDF غير المرتبط بعد.

## حدود التنفيذ
- الفرع الوحيد المتغير: `feat/maqwati-green-identity-isolated-20261121` داخل PR #64 المسودة.
- لم تُعدّل `main` ولا PR #62 ولا أي نموذج محاسبي أو خادم مالي أو صلاحيات اعتماد.
- لا تعرض معاينة الهوية أي أرصدة حقيقية دون جلسة موثقة.
- تعديلات الضبط تنظيم للواجهة فقط، لا ادعاء بتنفيذ تغيير كلمة المرور أو الدفع للاشتراكات.
- نسخة Android المعزولة تستخدم `com.maqwatilink.green_ui_preview`، ولا تحتوي صلاحية الإنترنت.
