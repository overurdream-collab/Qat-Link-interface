# مقوتي لينك — Yemen Modern Fintech UI / 2026-11-21

## الهدف والنطاق
تطوير هوية تطبيق مالية حديثة واضحة وسريعة الاستخدام، تجمع بين شخصية مقوتي اليمنية المعتمدة وإيحاءات القمريات والهندسة المعمارية الصنعانية، دون تحويل الشاشات إلى ملصقات مليئة بالزخارف.

هذه المرحلة **تنفيذ أساس الهوية وشاشة الدخول/التسجيل**، وليست إعلانًا عن استكمال جميع الشاشات أو جاهزية الإطلاق.

## ما نُفذ في هذا الفرع
- رأس هوية Flutter أصلي قابل للتكيف بعرض الشاشة، بارتفاع 168 بكسل للدخول و118 للتسجيل، بدلاً من الرأس السابق 293/190 بكسل.
- إبقاء صورة الشخصية اليمنية المحلية `assets/images/maqwati_approved_mascot.jpeg` مع بديل بصري إذا لم يتوفر الأصل؛ وتبقى النصوص حقولًا ومكونات Flutter فعلية وليست صورة شاشة.
- تصحيح العلامة إلى **«مقوتي لينك»** وعبارة **«حلقة وصل بينك وبين عملائك»**، دون وضع شعار رسوم بيانية أعلى الاسم.
- اعتماد لون الهوية الأساسي `#07575B`، والتركواز الثانوي `#168E94`، وحدود أسطح هادئة. اللمسة الذهبية `#D4A13E` للزخارف المحدودة.
- اعتماد وردي الإناث `#96295F` مع ثانوي `#CA5C8E` وخلفية `#FFF3F8`. الربط الموجود مسبقًا بين اختيار الجنس والثيم لم يُلغَ.
- الحفاظ على دلالات الحالة المالية المستقلة (نجاح/رفض/معلق): تغيير الثيم لا يغيّر معنى الدين أو السداد أو حالة الموافقة.
- الحفاظ على `MaterialApp.locale = Locale('ar')` والمفوضين الرسميين للترجمة، وإضافة اختبارات RTL والهوية والثيم الوردي.
- لم يُضف دخول بالشبكات الاجتماعية، ولم تُعدّل آلية تسجيل الدخول، ولم تُمنح جلسة دون مصادقة بالخادم.
